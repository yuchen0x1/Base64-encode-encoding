## 差距、平台与界面

DevToys 用桌面安装与工具检测覆盖多个桌面系统；Boop 适合键盘驱动的文本操作；IT Tools 和 CyberChef 展示了可直接打开的浏览器工作区。极客工具箱现有的桌面导航、搜索和可移植配方足以承载日常操作。关键差距是 v0.0.8 的工作区启动故障、配方缺少终端入口，以及安装与发布证据不足。参考 jq 和 Hoppscotch 把终端参数与流作为独立交互。保留 Windows 模块、工作区和已有壁垒较低的快捷操作。

配方共用纯逻辑，桌面保留 Worker 与可访问的开关，CLI 单独采用输入流、退出码、标准输出和错误流。取代 CryptoJS、扩展插件、浏览器相机和云端持久化均涉及独立的性能、许可证或隐私评估。MIT 与 BSD/Apache 许可证在保留声明的情况下可作为相应依赖的来源，本轮直接复用仓内代码与依赖，CLI 内嵌 CryptoJS 的 MIT 声明一并保留。GitHub 标记 NOASSERTION 的项目仅作为研究参考。
