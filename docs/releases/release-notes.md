## v0.0.6（2026-11-13）

修复安装更新后应用退出、没有重新打开的问题。

### 修复内容

- 修复点击安装并重启后应用退出却没有重新打开的问题：更新助手现在携带完整的 ICU 与 V8 启动数据。
- 安装前确认更新助手已经成功启动；缺文件、崩溃或超时时保留当前应用并显示错误，支持重试或手动安装。
- 更新助手独立运行，避免占用安装目录；新版本启动时显式使用安装目录，并处理启动进程错误。
- 阻止重复触发更新安装，改进临时运行文件的安全清理。

### 升级说明

- **从 v0.0.4 / v0.0.5 升级时，请先下载本版 Windows 安装包，手动覆盖安装一次。** 旧版本运行的是自身已有的更新器，单纯换成新的在线安装包不能修复旧助手启动失败的问题。
- 安装后启动应用，确认显示 v0.0.6；收藏、主题和标签页仍沿用原有配置，不需要卸载或删除用户数据。
- 本版以后，助手就绪确认和失败保护会参与后续自动更新。若助手未能启动，当前应用会保留并显示错误，不再直接退出。

### 发布范围与验证边界

- Windows x64 安装包与网页包；此修复主要针对 Windows 桌面更新链路。
- 安装包仍未签名。独立运行时、助手启动确认和失败保活已有真实进程测试；已验证原有 v0.0.4 手动覆盖安装到 v0.0.6 后正常打开、保留用户配置。旧版本自动安装并启动新版本的完整端到端验收尚未完成。

## v0.0.5（2026-11-13）

批量流程与数据可靠性升级：减少重复操作，保护输入与导出结果。

发布日期：2026-11-13（北京时间，Asia/Shanghai）。

### 新增功能

- 批量处理支持 1–8 步有序流程，可串联 Base64、URL、MD5/SHA 与 JSON 操作，并可增删、上下调整步骤。
- 提供 Base64 解码后美化 JSON、JSON 压缩后 URL 编码、Base64 解码后计算 SHA-256 三种常用配方。
- 支持配方 JSON 导入导出；配方只保存步骤及选项，不包含输入、结果或文件内容。

### 批量处理体验

- 计算移至后台，支持立即停止；已完成结果保留，进度按实际完成条目显示。
- 结果按每页 100 条展示，支持成功/失败筛选、关键词搜索和逐条复制；搜索覆盖完整来源文本。
- 每批最多 1000 条；文本单条 2 MiB、文件单个 64 MiB、输入合计 128 MiB，并对处理时间和结果大小设置保护。
- 运行时固定处理配置；修改流程后会提示旧结果仍属于上次运行，JSON 导出包含实际配方、状态和条目数量。

### 数据与功能修复

- JSON 美化和压缩保留原始数字文本，避免 64 位 ID 被四舍五入、高精度小数被截断或大指数数值变成 null。
- JSON 键排序和空值清理遇到会丢失精度的数字或重复键时拒绝执行并保留输入；深层 JSON 统计不再依赖递归，编辑后清除旧错误及 TypeScript 结果。
- Base64 解码后的字节可直接继续哈希或重新编码；文本步骤严格检查 UTF-8，损坏数据会标出失败步骤。
- CSV 导出正确引用单元格并处理公式前缀；需要逐字保留内容时可导出 JSON 或 TXT。
- 多个工具仅在剪贴板写入成功后提示已复制，权限拒绝或接口不可用时提供手动复制提示。
- 密码生成拒绝空字符集合，并保证每类已选字符至少出现一次；普通 HTTP 环境缺少原生 UUID 接口时使用安全随机字节生成 UUID v4。
- 修复搜索或分类只匹配一个工具时入口被隐藏的问题，增加无结果提示、重置筛选和键盘可操作的工具卡片。
- 修复大写十六进制 HTML 实体漏解码、非法十进制实体被部分读取的问题；二维码容量不足时显示错误并支持修改后恢复。
- 减少 Windows 安装包内不必要的依赖和 source map；更正二维码、颜色、文本工具的能力描述及没有实测依据的固定指标。

### 升级说明

- 从 v0.0.1 及后续版本升级：可在应用版本面板检查更新，也可下载本页 Windows x64 安装包手动安装。
- 网页版可使用本页 ZIP 部署，或配合网页更新服务使用 web-version.json；工作区收藏、标签页和主题格式保持兼容。

### 发布范围与说明

- 本页正式资产为 Windows x64 安装包、网页 ZIP 及对应更新清单；原生平台 CI 产物不等于本页提供了全平台安装包。
- Windows 安装包未签名；哈希和载荷校验不等于真实安装升级验收。颜色工具只接收 HEX，文本大小写操作目前仅转小写，二维码工具仅生成。

## v0.0.3（2026-11-13）

更新可靠性与工具正确性升级：加强下载校验、恢复处理和多种数据边界。

发布日期：2026-11-13（北京时间，Asia/Shanghai）。

### 更新与恢复

- 桌面更新仅接受支持的 Windows NSIS 安装包，下载后校验大小及 SHA-256；安装后确认应用载荷声明的版本与目标版本一致。
- 更新下载支持有限次数重试，并在服务端支持 Range 时继续下载已有部分。
- 更新清单支持可选的 Windows 数字签名校验；未提供签名时会如实显示，不能把哈希通过当成已签名。
- 安装助手增加等待文件释放、完成状态检查、失败重试及交互式安装回退，改善只装出部分文件的问题。
- 网页更新限制 ZIP 解压资源用量、检查路径与归档完整性，文件替换失败时执行恢复；静态服务收紧路径边界。

### 工具修复

- 修复 Base64、Base32、Hex 和转义工具的 Unicode、非法长度、字符与填充边界，减少错误解码和大文本编码异常。
- 改进 JSON 根值、键处理和 TypeScript 类型生成；JWT 解析区分尚未生效与已过期，明确标为仅解析、不验签。
- JWT 生成器校验输入对象及签名设置，输入变化后清除旧令牌；AES 校验密钥、IV 和密文格式。
- 哈希工具的主结果与所选算法保持一致；多进制转换保留负数与 BigInt 精度。
- 正则匹配移至隔离任务，超时终止，避免复杂表达式长期卡住页面；改进空匹配推进及结果限制。
- 图片 Base64 根据文件内容识别类型；二维码生成失败时清除旧预览；SQL 排版保护字符串及注释内容。

### 工作区体验

- 恢复收藏和标签页时过滤无效项，保留用户主动清空的收藏；常用分类的计数与搜索结果保持一致。
- 支持导入导出工作区偏好，迁移收藏、标签页、当前工具和主题，不包含工具输入。

### 升级说明

- 建议仍使用 v0.0.1 / v0.0.2 的用户升级；可从应用版本面板检查，也可手动安装本页安装包。
- 网页版提供 ZIP 和独立 web-version.json；version.json 用于桌面更新，不需要普通用户手动下载。

### 发布范围与说明

- 发布日期按 GitHub 首次发布时间换算为北京时间，更正旧日志中的 2026-11-11 为 2026-11-13。
- 上述校验和恢复属于实现能力，不代表所有设备的真实更新流程均已验收；JWT 解析不验证签名。
