## v0.1.4（2026-11-27）

## 📢 版本概述

本次修复编码、SQL、JSONPath、批处理和文本差异中的边界问题，加固图片格式识别、错误日志与安装包验证，并改进更新状态和本地清理。v0.1.3 用户可通过应用内更新获取本版；v0.1.2 用户需手动覆盖安装本版一次。

## 🔧 改进与优化

- `npm run clean` 现在覆盖 `dist-cli/`、`release-candidate/` 和项目根目录 `install.log`，与原有构建产物及临时验证目录一并清理。
- 将 `release-candidate/` 加入 Git 忽略规则，避免本地候选安装包及解包目录误入版本库。
- 清理时验证工作区边界，不沿目录链接递归，也不会把 `release-builder-source` 等近似名字误认为构建输出；删除失败会保留路径并返回失败状态。
- Windows 发布脚本直接启动已安装的构建工具，保留含空格和特殊字符的路径；Actions 中间产物保留 7 天。

## 🐛 问题修复

- Base64、Base32、Hex 解码及 Hex 反转义保留输入开头的 BOM；URL-safe Base64 正确忽略合法空格和换行。
- SQL 压缩不再修改引号字符串、标识符中的逗号与空白；格式化保留注释原文以及行注释后的语句边界。
- JSONPath 拒绝非法、超出安全整数范围及数值为零的切片步长，并及时执行递归查询结果上限。
- 批处理快速暂停、继续或停止后立即重跑时，上一轮清理不再关闭新一轮 Worker；差异统计正确计入新增和删除的空白行。
- 后台下载和安装状态不再被重复检查更新覆盖；被拒绝或未耗尽的 HTTP 响应会及时关闭。

## 🔒 安全与兼容性

- 图片格式识别使用顺序扫描，避免特制前导内容造成正则回溯卡顿；CLI 和更新错误日志转义控制字符。
- 安装包元数据使用已打开的同一文件句柄检查和读取；解包元数据必须与归档声明大小一致，并按上限读取。
- 保留既有 HTTPS、主机与重定向边界、安装包类型、大小及 SHA-256 校验；没有用户数据格式迁移。
- v0.1.2 的更新检查缺陷无法由新版本远程修复；该版本用户需手动下载并覆盖安装本版一次，之后可使用应用内更新。

## v0.1.2（2026-11-25，已发布）

### 性能与可靠性

- 二维码 WASM 仅在首次扫描时由 Worker 加载；清空、替换图片和组件卸载会取消文件读取与解码，Worker 初始化失败时停止剩余批次；Electron 烟测覆盖 2048 × 2048 图片识别。
- 大于 1 MiB 的 JSON 校验、美化、压缩、路径查询和结构操作使用 Worker；32 MiB 文本上限、5 MiB 树/路径限制和取消操作保护资源。美化结果限制为最多 100,000 行，超长单行 JSON 会拒绝应用格式化结果并保留原输入，避免 textarea 产生数 GB 级布局峰值。

- 生产 CSP 从 `connect-src` 移除 Vite localhost WebSocket 来源。
- 侧栏搜索和命令面板共享 NFKC、别名和多词匹配规则。
- Windows 更新下载对公开 GitHub Release 安装包使用官方优先；失败或持续低速后探测 GH-Proxy 与经 Range 核验的备用线路，按实测吞吐和延迟评分选线。重定向主机、无凭据请求、Range 响应、大小和 SHA-256 均有边界校验。

## v0.1.0（2026-11-24）

本版是 0.0.x 序列之后的功能与安全升级，工具输入仍在本机处理；二维码识别使用随包内联的 ZXing WASM，不访问 CDN，也不上传图片。

### 功能扩展

- 二维码工具新增“生成 / 识别”双向模式，可从本地 PNG/JPEG 图片离线识别，支持多图校验、进度、复制及 CSV/JSON 导出。
- JWT 工具新增显式“仅解析 / HS256 本地验签”模式，使用 Web Crypto 验证签名，密钥不会写入 localStorage；错误密钥、被篡改载荷和不支持算法均给出明确状态。
- JSON 工具新增树视图、JSONPath 风格路径定位、结构差异比较和派生 TypeScript 类型，保留大整数文本处理约定。
- 颜色工具支持 HEX/RGB/RGBA/HSL/HSLA/HSV/HSVA 与 Alpha 双向输入，使用共享规范化逻辑并加强非法输入保护。
- 工作区新增全局命令面板（Ctrl/Cmd+K）、快捷键帮助、最近使用列表和收藏/最近优先排序，工作区备份兼容旧格式。
- 21 款工具组件改为动态加载，并显示加载中/失败恢复态；主包体积显著下降。

### 安全与可靠性

- Electron 升级到 45.4.1。更新 IPC 仅接受主窗口、主 frame 和受信文档，外链限制为官方 HTTPS 域名白名单，导航、webview、设备权限和 CSP 同步收紧。
- `wasm-unsafe-eval` 仅用于本地内联 ZXing WASM；这是受控豁免，不等同于完整安全认证。预加载桥只暴露冻结的更新接口，不暴露 `ipcRenderer`。
- 更新器在窗口销毁、渲染进程崩溃或应用退出时取消下载与待发送事件，减少半包和监听器泄漏。
- 安装生命周期测试改为选择严格早于候选版本的已发布稳定版，避免发布过程中 `latest` 变化造成假失败。
- maintenance 工作流增加依赖审计、发布资产/摘要/CLI/证明校验、文档链接检查和上游仓库扫描，并提供 API 重试与清晰诊断。

## v0.0.5（2026-11-13）

批量流程与数据可靠性升级：减少重复操作，保护输入与导出结果。

发布日期：2026-11-13（北京时间，Asia/Shanghai）。

### 新增功能

- 批量处理支持 1–8 步有序流程，可串联 Base64、URL、MD5/SHA 与 JSON 操作，并可增删、上下调整步骤。
- 提供 Base64 解码后美化 JSON、JSON 压缩后 URL 编码、Base64 解码后计算 SHA-256 三种常用配方。
- 支持配方 JSON 导入导出；配方只保存步骤及选项，不包含输入、结果或文件内容。

### 批量处理体验

- 计算移至后台，支持立即停止；已完成结果保留，进度按实际完成条目显示。
- 结果按每页 100 条展示，支持成功/失败筛选、关键词搜索和逐条复制；搜索覆盖完整来源文本。
- 每批最多 1000 条；文本单条 2 MiB、文件单个 64 MiB、输入合计 128 MiB，并对处理时间和结果大小设置保护。
- 运行时固定处理配置；修改流程后会提示旧结果仍属于上次运行，JSON 导出包含实际配方、状态和条目数量。

### 数据与功能修复

- JSON 美化和压缩保留原始数字文本，避免 64 位 ID 被四舍五入、高精度小数被截断或大指数数值变成 null。
- JSON 键排序和空值清理遇到会丢失精度的数字或重复键时拒绝执行并保留输入；深层 JSON 统计不再依赖递归，编辑后清除旧错误及 TypeScript 结果。
- Base64 解码后的字节可直接继续哈希或重新编码；文本步骤严格检查 UTF-8，损坏数据会标出失败步骤。
- CSV 导出正确引用单元格并处理公式前缀；需要逐字保留内容时可导出 JSON 或 TXT。
- 多个工具仅在剪贴板写入成功后提示已复制，权限拒绝或接口不可用时提供手动复制提示。
- 密码生成拒绝空字符集合，并保证每类已选字符至少出现一次；普通 HTTP 环境缺少原生 UUID 接口时使用安全随机字节生成 UUID v4。
- 修复搜索或分类只匹配一个工具时入口被隐藏的问题，增加无结果提示、重置筛选和键盘可操作的工具卡片。
- 修复大写十六进制 HTML 实体漏解码、非法十进制实体被部分读取的问题；二维码容量不足时显示错误并支持修改后恢复。
- 减少 Windows 安装包内不必要的依赖和 source map；更正二维码、颜色、文本工具的能力描述及没有实测依据的固定指标。

### 升级说明

- 从 v0.0.1 及后续版本升级：可在应用版本面板检查更新，也可下载本页 Windows x64 安装包手动安装。
